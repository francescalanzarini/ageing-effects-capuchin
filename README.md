# ageing-effects-capuchin
This repository contains the code used for Lanzarini et al, "Ageing impairs economic choices in tufted capuchin monkeys" 
Data used are at https://doi.org/10.5281/zenodo.23266144

To define different experiments ("expr"):
  "tra" for Experiment 1, 
  "ftr" for Experiment 2 - Food condition, and 
  "ttr" for Experiment 2 - Token Condition.
